# Cloche Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `/cloche/`: a fruit fly under a glass dome whose brain is the FlyWire v783 connectome simulated live in the browser, with sugar, bitter, shadow and poke interactions.

**Architecture:** A one-off Node build script packs the public Codex CSVs into `cloche/data/brain.bin` plus `groups.json`. `cloche/brain.js` is a pure leaky integrate-and-fire simulator over that CSR graph (Shiu et al. 2024 dynamics) that runs identically under node (verify script) and in a Web Worker. The page is Three.js: a dome scene with a procedural rigged fly whose pose is driven by smoothed motor/descending firing rates, and a point-cloud brain window that flashes spikes.

**Tech Stack:** Vanilla ES modules, Three.js 0.165 via the CDN import map already used by `/unfold/`, Web Worker, Node 26 for build and verify. No bundler, no framework.

## Global Constraints

- Static GitHub Pages site; no server, no build step at deploy. Committed data must stay under 25 MB total.
- Simulator parameters are Shiu et al. 2024 exactly: V_rest = V_reset = −52 mV, V_th = −45 mV, τ_m = 20 ms, τ_syn = 5 ms, refractory 2.2 ms, delay 1.8 ms, w_syn = 0.275 mV per synapse, dt = 0.1 ms, GABA and GLUT presynaptic neurons inhibitory, all others excitatory.
- Data: FlyWire v783, connections summed per (pre, post) pair, keep pairs with ≥5 synapses. Expect N = 139,255 neurons, E = 2,700,513 edges.
- Page copy names the FlyWire Consortium (Princeton), Dorkenwald et al. 2024, Schlegel et al. 2024, Shiu et al. 2024, Eckstein et al. 2024, and states what is real versus staged.
- Page follows the `/unfold/` shell: same header, sidebar, palette variables, fonts, import map.
- Spec deviations already decided: **water** stimulus cut (Codex has no water class separate from sugar); **brain surface mesh** cut (navis does not install on this machine's Python); the point cloud carries the brain's shape. Record both in the spec's revision section in Task 8.
- Verified neuron group sources (from Codex v783 files):
  - sugar GRNs: `labels.csv` rows whose label contains "sugar gustatory receptor neuron" (case-insensitive), intersected with `classification.csv` sub_class `sugar/water` → 23 ids. Shiu's notebook lists 21 ids of which 20 exist in v783; assert at least 15 of those are in the set.
  - bitter GRNs: `classification.csv` sub_class `bitter` → 65 ids.
  - MN9: 720575940618238523, 720575940660219265. MN6: 720575940627410451, 720575940628826128.
  - GF: `consolidated_cell_types.csv` primary_type `DNp01` (2). DNa01, DNa02: primary_type (2 each).
  - LC4: primary_type `LC4` (104). LPLC2: `LPLC2` (210).
  - JO: primary_type starting `JO-C` or `JO-E` (26 + 196 + subtypes).
  - aDN: `labels.csv` label containing "putative adn" (few ids; grooming readout is soft, see Task 2).

**Interfaces:**
- Produces `brain.bin` layout, little-endian:
  ```
  magic  Uint8[4]  "CLO1"
  N      Uint32    neurons
  E      Uint32    edges
  bbox   Float32[6] minx miny minz maxx maxy maxz (nm)
  offsets Uint32[N+1]
  targets Uint32[E]   (absolute indices, no delta coding: gzip on the wire is enough)
  weights Int8[E]     signed synapse count clipped to ±127
  pos     Uint16[3N]  quantised in bbox
  cls     Uint8[N]    0 optic 1 central 2 sensory 3 visual_projection 4 descending 5 ascending 6 motor 7 endocrine 8 other
  ```
- Produces `groups.json`: `{ "sugar": [idx...], "bitter": [...], "MN9": [...], "MN6": [...], "GF": [...], "DNa01": [...], "DNa02": [...], "LC4": [...], "LPLC2": [...], "JO": [...], "aDN": [...] }` plus `"rootIds": { "MN9": ["7205...", ...] }` for display.
- Produces `data.js`: `decodeBrain(arrayBuffer) → { n, e, bbox, offsets, targets, weights, pos, cls }` and `CLASS_NAMES`.

### Task 2: Simulator

**Files:**
- Create: `cloche/brain.js`
- Modify: `scripts/verify-cloche.mjs` (part B)

**Interfaces:**
- `createBrain(data, { seed = 1 } = {}) → brain`
- `brain.stimulate(indices: Uint32Array|number[], hz: number)` sets Poisson drive; `hz = 0` clears.
- `brain.clearAll()`
- `brain.step(nSteps) → Uint32Array` neuron indices that fired during those steps (may repeat a neuron).
- `brain.rate(indices, windowMs = 200) → Hz` mean rate over the group from an internal spike-count ring.
- `brain.time` (ms), `brain.activeCount`.
- Constants exported: `DT = 0.1`, `W_IN_MV` (input weight, start 2.75 mV = 10 synapse-equivalents), `PARAMS`.

- [ ] **Step 1: Write part B of the verify script first** (failing): rest 1000 ms → 0 spikes; sugar at 100 Hz for 1000 ms → MN9 rate over last 500 ms in [20, 80] Hz; sugar + bitter both at 100 Hz → MN9 < 5 Hz; LC4 + LPLC2 at 150 Hz for 50 ms → ≥ 1 GF spike within 40 ms; JO at 140 Hz for 500 ms → print the 10 most active descending-class neurons and their rates, and `ok` if the aDN group rate > 5 Hz else print `soft` (not a failure); seeded determinism; wall time for the sugar second printed.
- [ ] **Step 2: Run it.** Expected: fails with "createBrain is not a function".
- [ ] **Step 3: Implement `brain.js`.** Float32 `v`, `g`; Float32 `refUntil`; a delay ring of 18 slots each a growable Uint32 list; an active set as a Uint32 array plus a Uint8 `inActive` flag; xorshift32 PRNG. Per step: (a) deliver the spikes due this slot: for each source j, loop CSR row and `g[t] += w * 0.275`, add t to the active set if not in it; (b) Poisson drive: for each stimulated neuron with probability `hz * dt / 1000` add `W_IN_MV` to g (stimulated neurons stay in the active set while driven); (c) integrate the active set with exact exponential Euler: `g *= e^{-dt/τs}` then `v += dt/τm · (Vrest − v + g)`; if `t ≥ refUntil && v ≥ Vth` → spike: v = Vreset, g = 0, refUntil = t + 2.2, push into ring slot `(slot + 18) % 18`, record in the returned array and in the rate ring; (d) drop neurons from the active set when `|g| < 1e-4 && |v − Vrest| < 1e-4` and not driven. Rate ring: per-neuron Uint16 spike counts in 10 ms bins, 50 bins.
- [ ] **Step 4: Run verify.** Expected: rest ok, sugar → MN9 in band, bitter suppression ok, GF ok. If MN9 is out of band, adjust `W_IN_MV` (only this constant) and re-run; record the final value in the spec revision. If GF does not fire, raise the looming burst to 250 Hz in the test and note it.
- [ ] **Step 5: Pick the grooming readout** from the printed top descending responders under JO drive: if the aDN label group fires, keep it; otherwise set `groups.aDN` in the build script to the two best-responding descending neurons that Shiu's paper names (aDN1/aDN2 are the antennal grooming DNs; their v783 ids will be among the top responders in the `descending` class) and rebuild. Re-run verify.
- [ ] **Step 6: Commit** "cloche: LIF simulator reproduces sugar → MN9 and bitter suppression".

### Task 6: The fly

**Files:**
- Create: `cloche/fly.js`

**Interfaces:**
- `createFly() → { group, setRates({ MN9, MN6, GF, aDN, DNa01, DNa02 }), gfSpike(), update(dt, world) , position, heading, hunger, labellumPoint() }`.
- `world` passed to update: `{ droplets, baseRadius, onReachDroplet(droplet), onLeaveDroplet(droplet) }`.

- [ ] **Step 1: Geometry.** Thorax (icosahedron r 0.9 scaled 1.2, 0.9, 1.0), abdomen (icosahedron r 1.0 scaled 1.0, 0.8, 1.6, striped via vertex colours), head (sphere r 0.6) with two red compound eyes (hemispheres, `#A43A2E` with a faint hex-bump normal from a canvas), two antennae (thin cones), a proboscis of two segments: rostrum (cylinder 0.6 long) hinged at the head, labella (two small flattened spheres) at its tip; six legs, each three segments (coxa-femur, tibia, tarsus) as thin cylinders with hinge pivots; two wings as flat `PlaneGeometry` with a translucent grey material and a drawn vein texture. Flat-shaded `MeshStandardMaterial`, slate `#3E4A5A`, ~1,200 triangles total. Everything is built into named pivots: `rostrum`, `labella`, `legL1..legR3` (each with `hip`, `knee`), `wingL`, `wingR`, `antL`, `antR`.
- [ ] **Step 2: Pose from rates.** Exponential smoothing τ 50 ms of each incoming rate. `rostrum.rotation.x = -1.1 · clamp(MN9/40, 0, 1)`; labella spread `0.4 · clamp(MN6/40, 0, 1)`; grooming when smoothed aDN > 10 Hz: forelegs swing over the antennae on a 3 Hz loop, antennae bob; jump on `gfSpike()`: 120 ms parabolic arc of height 8 mm to a random landing point ≤ 15 mm away inside the base, wings flick open for the arc, 600 ms cooldown.
- [ ] **Step 3: Locomotion controller** (staged): `hunger` rises linearly 0→1 over 240 s and drops by 0.4 per droplet consumed. Each frame choose a mode: `feeding` if labellum within 1.5 mm of a droplet (stop, call `onReachDroplet` once); `seeking` if hunger > 0.25 and a sugar droplet exists (turn toward nearest at 3 rad/s, walk at speed 6 mm/s × (0.4 + 0.6 · clamp((DNa01+DNa02)/20, 0, 1)) — descending rates only modulate); else `idle`: random walk with 1–3 s pauses and 0.5–2 s walks of 4 mm/s, turning away from the base edge when within 5 mm of it. Tripod gait: phase clock at 8 Hz while walking, legs L1 R2 L3 in phase, the others anti-phase, hip swings ±0.35 rad, knees lift on swing. When a droplet is done (`radius ≤ 0`) leave feeding after 400 ms and call `onLeaveDroplet`.
- [ ] **Step 4: Manual check** with `fly.setRates({ MN9: 40 })` from the console: proboscis extends; `fly.gfSpike()` jumps; idle wander stays on the base.
- [ ] **Step 5: Commit** "cloche: procedural fly with rig, gait and hunger".
